# NEDOPULSE Consulting Group — website starter

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL Vite gives you (normally http://localhost:5173).

## Build for production

```bash
npm run build
```

The production files will be in `dist/`.

## Before launch

- Replace the placeholder email in `src/App.jsx`.
- Replace template demo links with your real template routes.
- Replace stock template images with your final template screenshots.
- Add your real social links.
- Connect the contact/quote form later.
- Buy the domain only when you're ready to publish. You can build and test everything locally first.

The visual direction follows the supplied NEDOPULSE mockup: dark navy/black base, cyan/blue primary glow, purple secondary glow, glassy cards, compact typography and strong CTA buttons.
